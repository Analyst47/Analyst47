### 🔐 VulnerabilityTrackerXL
A cybersecurity dashboard that tracks, scores, and visualizes enterprise vulnerabilities, with CVE and CVSS analysis layered on top of CISA KEV prioritization so the most dangerous findings surface first. Automated CSV import, severity breakdowns, and SOC style reporting built on Python and Google Apps Script.

### 🎣 PhishDetect SOC Dashboard
A real time phishing URL analysis tool that mirrors a Security Operations Center workflow. It classifies URLs as safe, suspicious, or malicious using heuristic scoring across HTTPS usage, URL structure, and suspicious keywords, then explains the reasoning behind every verdict. Runs fully in the browser with interactive charts.
